# AdsBanner

Android 端的开屏广告跳过与误触跳转拦截工具。

通过无障碍服务识别其他应用开屏页上的「跳过」按钮并自动点击；启动期间检测到广告、且没有主动操作却被拉起淘宝、京东这类应用时，尝试返回原应用。拦截次数按应用统计，可以在应用内查看。

广告识别和统计全部在本机完成，不采集任何数据。联网仅用于手动检查和下载更新、查看更新日志及其中的图片。

## 功能

- **开屏广告跳过**：进入应用后自动识别并点击「跳过 / 关闭广告」按钮，文案匹配结合屏幕位置判断，减少误点
- **误触跳转拦截**：识别开屏广告期间的可疑自动拉起；点击、滚动和系统导航优先放行，减少打断正常购物
- **拦截名单**：拦截目标可自行勾选，默认包含主流电商、短视频和浏览器
- **页面内广告清理**：按需关闭哔哩哔哩播放页的暂停广告
- **按应用统计**：分别记录开屏、跳转与页面内广告的今日、累计次数，支持分类筛选与热力图；旧版本已保存的来源统计保留为历史记录
- **桌面快捷入口**：长按应用图标，点击「统计」直接打开拦截统计，返回后进入主页
- **后台存活**：常驻通知提升进程优先级，开机后自动恢复
- **应用内更新**：通过 Release 附件接口下载，断线后有限重试并尝试续传；完成后校验大小、SHA-256、包名和版本，再交给安装器，重复点击不会另起下载任务
- **更新日志**：主页面底部查看全部历史版本及精确到秒的发布时间；优先显示本地缓存并在后台刷新，断网时仍可查看已保存内容，点选查看完整 Markdown 说明，返回时保留目录位置

## 工作原理

两条能力各自独立：

1. **开屏跳过**：应用切到前台后，在 10 秒窗口内遍历其可访问性节点树，找出文案命中规则且位置合理的「跳过」类控件并点击。文案分强、弱两级 —— 强匹配（跳过、关闭广告、skip）允许在顶部区域点击，弱匹配（关闭、×）只在右上角点击，避免关掉正常弹窗。

2. **跳转拦截**：只有来源应用仍在启动检测期、近期出现带广告标记或倒计时的顶部跳过按钮、且没有主动点击或滚动时，才对名单内应用的拉起安排返回。普通页面变化不重置启动时间；桌面、通知栏、分享选择器和近期返回应用等场景优先放行。等待期间若用户点击了来源或目标应用、切到别的窗口或关闭守护，就取消返回；发送前还会重新检查实际活动窗口，只返回一次。关闭开屏跳过后，跳转守护仍可独立识别广告上下文。

系统界面、vivo 系统界面组件及闹钟应用不参与自动点击和跳转返回；闹钟应用同时按系统声明的闹钟、计时器入口识别。普通倒计时不能作为点击“关闭 / ×”的广告证据，避免把亮屏闹钟提示误当开屏广告。

## 权限与限制

需要在系统设置中手动开启无障碍服务，应用无法自行授权：

| 权限 | 用途 |
| --- | --- |
| 无障碍服务 | 读取其他应用界面节点、模拟点击与返回 |
| 通知权限 | Android 13+ 显示常驻通知与拦截提示 |
| 开机自启 | 重启后恢复守护 |
| 电池优化白名单 | 避免休眠时服务被断开 |
| 网络权限 | 手动检查和下载更新、读取历史日志及其中的图片 |

系统层面的限制：

- 没有任何 API 能在点击落地前拦截 Intent 跳转，无障碍服务只能观察和模拟操作。因此跳转拦截一定是「先跳过去、再立刻退回来」，会有一帧闪现
- 摇一摇触发的跳转无法阻止，只能等它跳完再返回
- 无障碍无法可靠区分一次点击是主动购物还是误触广告，因此优先放行检测到的主动操作；部分广告点击会随之放行，缺少可访问广告节点的自动跳转也可能漏拦
- 开屏广告若在 WebView 或自绘 Surface 中渲染，节点树拿不到内容，无法识别
- Android 14 起，非应用商店渠道安装的应用，无障碍开关会落在「受限设置」中，需要在应用信息页点「允许受限设置」
- 被手动「强行停止」后所有服务失效，需重新打开应用

## 使用

1. 安装后打开 AdsBanner，点「去开启」进入系统无障碍设置，开启「AdsBanner · 广告拦截服务」
2. 回到应用，状态显示为运行中即生效
3. 按需到「跳转拦截名单」调整要拦截的应用
4. 如需在清理后台后保持存活，点「加入电池优化白名单」，并参照应用内的国产 ROM 指引放行自启动与后台运行

## 构建

需要 JDK 17 与 Android SDK（compileSdk 35）：

```bash
./gradlew assembleDebug
./gradlew assembleRelease
```

更新检查、历史日志与安装包下载均使用 GitHub 的公开接口，无需配置 key，APK 不注入 GitHub 访问凭据。匿名 API 访问受 GitHub 的 IP 额度与网络条件限制；额度用尽时会明确提示，已缓存的更新日志仍可查看。

产物位于 `app/build/outputs/apk/`，文件名形如：

```
AdsBanner-debug-v-2-1-1.apk
AdsBanner-release-v-2-1-1.apk
```

Release 使用本机 debug keystore 签名，可直接安装；覆盖安装时新旧包签名需一致。

## 项目结构

```
app/src/main/java/com/adsbanner/clean/
├── core/          配置、统计存储、跳过规则、应用信息缓存
├── service/       无障碍服务、前台常驻服务
├── receiver/      开机广播
└── ui/            主界面、统计页、拦截名单
```

## 说明

本项目仅供学习交流使用。广告拦截依赖各应用自身的界面结构，应用更新后可能需要调整识别规则。

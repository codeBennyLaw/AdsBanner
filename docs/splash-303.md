# 3.0.3：带分隔符的倒计时按钮

反馈截图右上角是“2s｜跳过”。3.0.2 能匹配“2s 跳过”和“跳过｜2s”，却不接受倒计时在前、分隔符居中的写法，完整文本无法成为跳过候选。

本轮将前置倒计时与跳过动作之间的单个分隔符纳入完整文案匹配，支持 `|`、`｜`、`丨`、`/`、`·`、`•`，同时补齐不带单位时的恢复检测证据。文字仍须是一至两位数字、可选秒单位、单个可选分隔符及完整“跳过”动作。

部分按钮会把“2s｜”放在文字中、“跳过”放在描述中，或将二者放在同一小型可点击父控件内的兄弟节点上。组合时只允许从倒计时片段的一端移除一个分隔符，再校验完整倒计时；不会清除句子内部文字或连接页面远处的数字。“2s后｜可跳过”“2s｜跳过登录／教程／闹钟”、三位数字及重复分隔符不会成为匹配。

## 录屏对照

在专用 Android 16 模拟器上，以正式发布的 3.0.2 APK 和修复版运行同一组模拟布局，检查真实关闭、成功统计及广告区域误点。新增完整文案测试先在旧规则失败，再在修复后通过。

| 场景 | 3.0.2 | 3.0.3 |
| --- | --- | --- |
| “2s｜跳过”及其他单分隔符变体 | 漏跳 | 关闭 |
| 无单位“2｜跳过”、空白及换行 | 漏跳 | 关闭 |
| 同控件文字“2s｜”、描述“跳过” | 漏跳 | 关闭 |
| 状态栏附近、底部留白上方的同类按钮 | 漏跳 | 关闭 |
| 控件重建、延迟出现、仅触摸响应 | 漏跳 | 关闭后只计一次 |
| 原检测窗口结束后，同包页面返回出现同类按钮 | 漏跳 | 关闭 |
| 冷启动中按钮内的数字、跳过分为节点，或分隔符单独成节点 | 关闭 | 关闭 |
| 普通数字、教程、登录、未来可跳过及重复分隔符 | 不点击 | 不点击 |
| 点击无效的按钮 | 未识别 | 有限重试，不计成功 |

修复版通过 93 项新场景检查、60 项 3.0.2 前置数字回归及 41 项亮屏、分享返回检查，共 194 项；对照版另完成 93 项检查。170 项单元测试通过，Debug、Release 已构建，lint 无错误、有 177 项警告。录屏所用的已安装 Debug APK 与最终构建文件哈希一致。

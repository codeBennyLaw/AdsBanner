# 精确本地规则

在「拦截管理」新增、编辑、启停或导入导出规则。仅用于能提供无障碍节点的原生开屏控件，不支持截图识别、脚本或小程序页面。规则执行仍受开屏广告自动跳过开关、暂停状态、例外应用及系统保护限制。

## 填写方式

- **应用包名**：可从已安装应用中选择，也可手动填写。
- **页面前缀**：应用 Activity 的完整类名前缀。建议填写具体广告页；留空时该应用启动窗口内的页面均可参与匹配。
- **完整节点 ID**：例如 `example.app:id/skip_ad`，可从应用的无障碍节点信息获得。页面上的文字不是节点 ID。
- **匹配文字**：可选，填写后须与目标当前文字完全一致；不支持正则表达式。
- **位置**：默认顶部，也可收紧至右上角。「指定页面任意位置」必须填写页面前缀，仍只允许小尺寸目标。
- **匹配时长**：从该应用进入前台开始计算，1–10 秒；不会因页面刷新而重新计时，也不能扩大总开屏检测窗口。

精确规则优先，未匹配时继续尝试通用开屏规则。成功执行一次后结束本次启动检测。禁用某条规则只关闭该条规则；需要对应用彻底放行，请将应用加入例外。

点击前会重新核对应用、窗口、页面、文字、位置和尺寸。系统界面、桌面、闹钟/计时器及已识别的小程序页面不参与自动点击，本地规则不能解除这些限制。规则失效或漏拦时不会自动点击任意位置。

## 文件格式

以下包名和节点 ID 仅为格式示例，不会默认启用：

```json
{
  "schemaVersion": 1,
  "rules": [
    {
      "id": "example-splash",
      "name": "示例开屏广告",
      "packageName": "example.app",
      "activityPrefix": "example.app.AdActivity",
      "viewId": "example.app:id/skip_ad",
      "text": "跳过广告",
      "region": "TOP_RIGHT",
      "maxAgeMs": 5000,
      "enabled": true
    }
  ]
}
```

`region` 仅接受 `TOP`、`TOP_RIGHT`、`PAGE`。`PAGE` 要求非空 `activityPrefix`。`activityPrefix`、`text` 默认空，`region` 默认 `TOP`，`maxAgeMs` 默认 `10000`，`enabled` 默认 `true`。其他字段必填；规则 `id` 须唯一。

单个文件不超过 256 KB，总计不超过 100 条，每个应用不超过 10 条。格式版本、字段、类型、大小、数量及保护边界均会校验；不接受 GKD 或其他应用的规则文件。

导入后先显示替换确认，确认才整体替换当前本地规则；无效文件不会改动已有规则。导出只包含本地规则，不包含例外应用、统计或最近操作。请只导入了解其含义的规则，先用具体页面和右上角等较窄范围确认效果。

## 本地数据

规则、例外名单及暂停状态使用独立存储，保留原有统计和开关。最近操作可关闭，最多保留 100 条开屏及跳转记录，仅含应用、时间、动作和规则名称；跳转记录另含来源应用。不会保存页面全文、截图，也不会上传。B 站暂停广告仍计入原有页面内广告统计，不写入此操作列表。

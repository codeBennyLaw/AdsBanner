# 3.1.2 普通文字误点击与返回循环修复

## 问题与判断边界

普通页面的可点击入口恰好显示「跳过广告」等文字时，3.1.1 会把它作为强匹配目标点击。用户从详情页返回后，应用内窗口切换又可能重新开启扫描，从而再次点击同一入口。无点击动作的文本也可能借由坐标兜底点到背景。

3.1.2 将文案匹配与点击授权分开。通用目标必须具有自身或紧贴父控件的点击动作，并通过开关、输入框、滚动控件及父控件动作文案检查。强匹配还要求以下至少一项：

- 完整的跳过倒计时，包括现有中文、英文和前置数字格式。
- 明确的广告动作节点 ID；设置、开关、标题、摘要等 ID 不作为证据。
- 同窗口相近位置的独立小型广告标记；「广告设置」「会员免广告」等文字不作为标记，目标自身也不能为自己提供独立证据。

普通「跳过广告 / 关闭广告 / skip ad」入口即使可点击，也不能仅凭这几个字触发自动点击。未能确认上述条件的目标会被放过，因此部分缺少可访问按钮动作或广告证据的广告可能不再自动跳过。精确本地规则仍按用户配置单独校验。

跳转保护复用同样的目标判断，只把引擎正在提交的跳过点击视为自动操作；用户点击同名入口仍属于主动操作。点击、长按和滚动结束整轮开屏扫描。应用内 Activity 切换不重新分配检测时间，已结束的扫描也不会因临时窗口返回重开；新的应用前台切换或亮屏解锁可以开始新检测。

## 同场景回归

使用已连接的 Android 11 / API 30 模拟器，分别运行已安装的 3.1.1 与 3.1.2 Release 包。独立模拟应用投递真实无障碍事件，并记录控件点击、背景点击和关闭次数；探针同时核对 AdsBanner 的成功统计。

| 模拟页面 | 3.1.1 | 3.1.2 |
| --- | --- | --- |
| 普通可点击「跳过广告」入口 | 自动点击一次 | 不点击 |
| 无点击动作的倒计时说明文字 | 背景收到三次点击 | 文本与背景均不点击 |
| 显示匹配文案的开关 | 自动点击一次 | 不点击 |
| 引导页普通「跳过」 | 自动点击一次 | 不点击 |
| 「广告设置」旁的同名入口 | 自动点击一次 | 不点击 |
| 远处存在广告标记的同名入口 | 自动点击一次 | 不点击 |
| 设置用途的广告相关节点 ID | 自动点击一次 | 不点击 |
| 中文、英文、前置分隔倒计时按钮 | 关闭一次 | 关闭一次、统计一次 |
| 无倒计时、具备广告动作 ID 的按钮 | 关闭一次 | 关闭一次、统计一次 |
| 无倒计时、邻近独立广告标记的按钮 | 关闭一次 | 关闭一次、统计一次 |
| 点击普通入口后，连续三次返回 | 共自动点击四次 | 自动点击零次 |

另验证成功跳过后进入详情、返回原页时，不重新点击重新出现的按钮；用户点击普通控件后，延迟出现的匹配按钮也不会被扫描。首轮通过 39 项模拟器断言与 178 项单元测试，Debug、Release APK 均已构建。

本地模拟页面、驱动及原始结果位于忽略目录 `app/build/ui-review/splash-312`，不随应用发布。探针结束后恢复模拟器原有保护配置、统计和无障碍开关。本次没有连接真实平板或实体手机，结果覆盖上述模拟流程，未逐一验证第三方应用当前版本。

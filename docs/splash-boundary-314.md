# 3.1.4 通用开屏误点与漏跳补充修复

## 复现与原因

前一轮跨版本回归中的 62 个场景结果一致，但没有覆盖可点击倒计时按钮的完整祖先层级和设置标记来源。本轮以此前的 3.1.4 Debug 为基线，增加 20 个模拟场景，直接核对按钮关闭、动作次数、父节点点击、统计和实际前台应用。

基线出现三类问题：

- 设置 ID、设置父容器、十层嵌套后的设置容器，以及滚动容器里的自身可点击或由紧凑父节点代点的倒计时控件，都被点击。原检查找到点击动作后立即返回，未继续核对外层；设置 ID 词表还遗漏了复数 `preferences`。
- 目标的节点动作返回失败时，继续向上尝试，点击到了描述「查看广告详情」的父节点。设置区域内的独立「广告」文字也可以为普通「跳过」提供证据。关闭开屏跳过、单独开启跳转保护时，设置控件和设置区域的广告标记分别造成一次错误返回购物应用。
- `Skip 5`、`Skip (5s)`、`5 Skip`、`Skip | 5s` 和 `5s | Skip ad` 五种完整按钮文案均未识别。

这些复现来自本地模拟页面，不是用户手机中的实际应用节点。基线跳转补查等待最近返回豁免期结束，避免该豁免掩盖证据错误。

## 修复行为

- 找到自身或紧凑父节点的点击动作后，继续核对至多 30 层祖先。设置、搜索、输入、开关以及通用滚动或分页容器阻止自动动作；未能在检查预算内完成的层级不执行。
- 明确的广告动作 ID 和已识别独立开屏页仍可提供专属证据，允许控件位于非设置的滚动祖先中；滚动容器自身不能作为借用点击动作的目标。新增专属 ID 滚动正例核对该兼容行为。
- 独立广告标记也核对其祖先层级，不能从设置、搜索或普通滚动内容借用证据。开屏跳过与独立跳转保护复用这项校验。
- 节点动作失败后，借用紧凑父节点动作时再次检查父节点类型、ID 和文案；不向描述其他操作的父节点点击，也不在这类失败后改用坐标触摸。
- 补齐英文前后置数字、单个分隔符和括号格式。倒计时证据直接基于完整按钮文案的严格匹配，避免文字识别与证据校验采用不同的格式列表。同一控件里的数字文字与 `Skip` 描述也能组合。

## 本轮验证

221 项单测通过，失败和错误均为零；Debug、Release 构建通过，版本保持 3.1.4（24），两种 APK 签名一致。

20 个新增场景通过 65 项模拟断言：五个英文漏跳恢复为关闭一次、统计一次；七个开屏误点场景没有点击或计数；两个错误跳转返回场景保持在购物应用。正常倒计时跳过、明确 ID 的滚动容器控件和有安全广告证据的自动跳转仍按预期处理。普通引导页、将来时文案和滚动页面的跳转负例保持放行。

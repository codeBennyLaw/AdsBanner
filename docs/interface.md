# 3.0.0 界面调整

主页按广告拦截、管理、后台运行和系统设置分组。统计使用蓝色底，拦截管理使用青绿色底；服务运行与未开启、暂停状态使用不同底色，普通设置保留中性容器。深浅色分别定义这些色阶，避免卡片与页面背景混在一起。说明文字直接描述功能。

卡片圆角统一为 28dp，输入框与按钮为 24dp，普通弹窗为 32dp，应用图标为 16dp。更新日志直接在中央展开弹窗，不绘制或移动入口按钮。其他弹窗与页面从入口区域展开；返回时收起的是原有内容，入口保持可见。

Android 14 起页面往返共用等比缩放与裁切路径；Android 10 起弹窗展开也复用绘制内容。两者通过单独的内容淡出和底色过渡衔接样式，保留尾段直至接近入口。返回位置依据实际可见边界，入口文字或父布局更新时先等布局完成；部分露出的卡片仍支持返回过渡。展开途中返回沿当前路径反向，取消返回保留当前姿态与近期速度。

统计、名单和拦截管理沿用相同的字重、间距与容器。名单说明放在搜索框上方，去掉重复的大色块；统计数字去掉蓝色徽章。热力图的分档和颜色保持原样。宽度达到 600dp 时增加页面边距，窄屏或大字体下页脚空间不足时分行显示。

统计右上角按「热力图 / 列表」较长文字预留宽度，切换时保持大小与右边缘不变，字体设置改变后重新测量。列表与热力图同时保留到交叉过渡结束，快速反向切换承接当前透明度和位置；实际显示的视图置于上层接收操作。转场期间延后的列表、图标刷新按帧交付，并合并同一键的旧任务，避免结束时集中更新。

继续使用 XML Views 与项目已有的 Material Components，没有新增依赖、自定义字体或持续运行的视觉效果。功能开关、统计口径和广告识别策略不变。

在独立 Android 16 / API 36 模拟器检查深浅色与 320dp、2 倍字体；录屏覆盖页面和弹窗的取消、再次拖动与返回，以及展开中途关闭、快速切换和部分可见入口。额外核对弹窗终点边界、按钮尺寸稳定和分帧任务交付，编辑表单检查软键盘及系统关闭动画设置。深浅色的关键文字与容器对比度逐项检查。没有操作实体手机，旧 Android 的回退路径未在对应系统上实测。诊断脚本、录屏和预览数据保存在忽略目录 `app/build/ui-review/motion-refine`。

# 3.0.0 界面调整

主页按广告拦截、管理、后台运行和系统设置分组。统计使用蓝色底，拦截管理使用青绿色底；服务运行与未开启、暂停状态使用不同底色，普通设置保留中性容器。深浅色分别定义这些色阶，避免卡片与页面背景混在一起。说明文字直接描述功能。

卡片圆角统一为 28dp，输入框与按钮为 24dp，普通弹窗为 32dp，应用图标为 16dp。更新日志借用入口按钮的实际可见边界，展开弹窗自身到完整尺寸，不绘制或移动入口按钮；展开途中可以跟随预测返回，取消后继续展开。状态文字预留换行空间，读取提示、缓存刷新和版本数量切换时保持弹窗高度稳定。首批版本内容到达后淡入，后续刷新保留列表位置。类型、排序、编辑与应用选择弹窗共用更新日志的自身展开路径；子页面和弹窗返回时整体收回自己的内容与底色，入口保持可见。

Android 14 起页面往返共用等比缩放与裁切路径；弹窗收起直接变换真实面板。两者使用相同的收起节奏，保留自身底色和内容直至接近入口，不渐变成按钮样式。返回位置依据实际可见边界，入口文字或父布局更新时先等布局完成；部分露出的卡片仍支持返回过渡。展开途中返回沿当前路径反向，保留切换瞬间的底色与内容透明度；取消后从当前样式继续恢复，手势再次拖动也承接当前姿态与近期速度。

统计、名单和拦截管理沿用相同的字重、间距与容器。名单说明放在搜索框上方，去掉重复的大色块；统计数字去掉蓝色徽章。热力图的分档和颜色保持原样。宽度达到 600dp 时增加页面边距，窄屏或大字体下页脚空间不足时分行显示。

统计的应用记录、每日热力图、应用名单、例外名单、管理页规则和操作记录，以及规则编辑中的应用选择、更新日志目录首次读取时，仅在各自的数据区域显示基础周期为 280ms 的短加载动效，遵循系统动画缩放；较慢的读取继续等待，失败可以重试。模型先在后台准备，再于动效周期结束后绑定视图，完成布局后，用 240ms 交叉淡入真实数据并淡出加载提示，读取提示的波形持续到交接结束。模型绑定前先将数据设为透明，等待布局后的绘制时机再交叉展示；列表中新挂载的行跟随同一展示进度，标题与筛选不参与淡入。列表加载层放在 RecyclerView 外，覆盖标题、筛选或搜索下方的剩余数据视口；它不占列表行高，空结果提示也按实际状态增删列表项。标题、说明、搜索和筛选保留显示并可操作。已有信息的筛选、排序、开关操作不重复首屏加载。隐藏的统计模式暂停等待动效；返回手势与收起期间继续绘制真实内容，保留现有控件与加载动效；模型更新通过转场队列延后交付，窗口移除或页面销毁后释放动画；关闭系统动画后没有额外的动效等待。

统计右上角按「热力图 / 列表」较长文字预留宽度，切换时保持大小与右边缘不变，字体设置改变后重新测量。列表与热力图首次切换先展示相应的局部加载，已有数据的切换先准备目标内容并完成布局，再开始交叉过渡，同时保留到过渡结束；快速反向切换承接当前透明度和位置，实际显示的视图置于上层接收操作。转场期间延后的列表、图标刷新按帧交付，并合并同一键的旧任务，避免结束时集中更新。

继续使用 XML Views 与项目已有的 Material Components，没有新增依赖、自定义字体或后台常驻动效。功能开关、统计口径和广告识别策略不变。

在独立 Android 16 / API 36 模拟器检查深浅色与窄屏大字体；录屏覆盖页面和弹窗的取消、再次拖动与返回，以及展开中途关闭、快速切换和部分可见入口。额外核对首批内容遮挡、加载周期、慢读取、重试、取消待展示内容和系统关闭动画，编辑表单检查软键盘及重建恢复草稿。没有操作实体手机，旧 Android 的回退路径未在对应系统上实测。加载区域诊断保存在忽略目录 `app/build/ui-review/data-region`，上一轮统一收起路径的诊断在 `app/build/ui-review/retraction`，本轮动态窗口与加载交接的录屏在 `app/build/ui-review/live-return`。

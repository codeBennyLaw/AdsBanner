# 3.0.0 界面调整

主页按广告拦截、管理、后台运行和系统设置分组。状态与统计使用中性底色，蓝色主要用于开关、选中项和操作入口；说明文字直接描述功能，不再重复宣传语或系统接口名称。

卡片圆角统一为 28dp，输入框与按钮为 24dp，普通弹窗为 32dp，应用图标为 16dp。弹窗展开时读取入口控件的实际形状，并使用与弹窗外观一致的目标圆角；返回仍收起弹窗自身，入口保持可见。统计入口的转场底色同步为中性卡片色。

统计、名单和拦截管理沿用相同的字重、间距与容器。名单说明放在搜索框上方，去掉重复的大色块；统计数字去掉蓝色徽章。热力图的分档和颜色保持原样。宽度达到 600dp 时增加页面边距，窄屏或大字体下页脚空间不足时分行显示。

继续使用 XML Views 与项目已有的 Material Components，没有新增依赖、自定义字体或持续运行的视觉效果。功能开关、统计口径和广告识别策略不变。

本次在独立 Android 16 / API 36 模拟器检查深浅色、320dp 宽度、1.6 和 2 倍字体；录屏覆盖页面及弹窗返回、取消与再次拖动，编辑表单检查软键盘和保存取消操作。没有操作实体手机，模拟器结果不代表国内厂商系统的实际表现。诊断脚本、录屏和预览数据保存在忽略目录 `app/build/ui-review/ui-rebuild`。

## 实机操作

1. 覆盖安装文件名含 `cn-probe-20261126-2` 的诊断 APK。
2. 打开 AdsBanner 的「拦截实时提示」诊断弹窗，确认顶部出现「诊断构建：cn-probe-20261126-2」。
3. 打开菜鸟复现一次开屏，返回 AdsBanner 后再次打开诊断弹窗，点击「复制」。
4. 反馈完整报告，尤其是菜鸟记录下面的「扫描状态」和「菜鸟结构样本」。没有结构样本时也保留完整报告，以区分未扫描、窗口不可读和启动检测被中断。

一键复制包含构建标识、历史结果、结构样本与通知状态；复制后弹窗继续显示，点空白关闭。

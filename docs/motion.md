# 3.0.0 交互与开屏状态恢复

## 跟手返回

- 子页面直接使用系统返回进度，不再叠加一次缓出曲线。纵向拖动采用连续的阻尼限制，避免到边界时突然停止。
- 页面展开与返回共用等比缩放和裁切计算，展开途中可沿当前路径反向，保留反向瞬间的底色和内容透明度，取消后从该状态恢复。入口部分可见时仍返回其可见区域，等待入口及父布局更新后再固定终点。返回保留页面自身底色和内容，接近入口后再淡出，不向原卡片颜色变形；页面与弹窗共用 300ms 收起节奏。
- 取消返回时，弹簧承接近期手势速度；回弹途中再次拖动从当前姿态继续。提交返回也从当前姿态接入返回入口的过渡。
- 父页面首个缓冲区尚未就绪时，短时重放它自己的显示列表，避免手势等窗口绘制。真实帧就绪后立即释放；承载视图预先挂载，手势期间切换可见性，不增删布局。
- 弹窗同样支持系统返回的开始、进度、取消及提交。收起时移动、裁切和淡出弹窗自身，入口按钮保持可见，不把弹窗缩成按钮。
- 类型、排序、编辑、应用选择与更新日志共用弹窗自身展开的路径：从入口的实际可见边界展开，不复制或移动入口文字；展开途中可跟随预测返回，取消后接续。更新日志状态文字预留换行高度。收起直接变换原生面板，保留内容与底色，接近入口再淡出；控件动画与文字变化继续绘制，避免收回途中变成按钮或固定画面。手势提交和取消回弹使用近期速度，减少松手时的突变。
- 子页面在稳定的外层容器上执行缩放、裁切与位移，内部真实视图始终挂载；弹窗直接变换原面板。无需截取或重复录制关闭中的界面，不冻结已有控件动画。提交关闭后拦截新的触摸，原有动态继续到窗口移除。
- 取消、关闭和生命周期结束时恢复裁切、轮廓及列表状态，释放临时绘制资源。系统关闭动画时跳过视觉变换；编辑器先由系统返回收起键盘，再关闭弹窗。
- 列表与热力图使用连续交叉过渡，快速反向时保留当前姿态。转场后延迟的刷新按帧交付，同一键只保留最新任务，不在结束的一帧集中处理。
- 首批本地信息在各自的数据区域以 280ms 基础周期显示读取动效，保留周围的说明和操作，在周期结束后的静止帧绑定模型并完成布局，再在同一数据区域用 240ms 交叉淡出加载提示、淡入数据；先设透明再显示，加载波形持续到交接结束。新挂载的列表行跟随当前透明度，初次展示期间不叠加列表自身的插入动画。列表加载层不再作为 RecyclerView 的一行，覆盖头部下方的可用视口；结束后不保留行高，空结果信息按状态插入或移除；隐藏的统计模式停止绘制等待动效；返回手势与收起不暂停已经可见的动态；仅将新的模型交付留给转场队列，关闭时撤销尚未交付的模型。列表与热力图首次切换展示各自占位，后续切换等目标内容布局后再动，避免读取、布局与移动挤在同一帧。

父页面首帧就绪前的短时桥接只使用本应用自己的显示列表；关闭中的页面与弹窗始终绘制真实视图，不读取其他应用图像，也不保存截图。

## 开屏失效修复

通用开屏识别在没有任何本地规则时也会执行。本地规则只是可选补充，管理页面已明确说明。

此前息屏缓存若没有收到后续解锁通知，可能一直阻止扫描。现在窗口变化会复查真实亮屏和锁屏状态；缓存为不可用时，内容事件也可触发复查，间隔至少 250ms。没有新增常驻定时轮询，锁屏仍禁止自动操作。同一应用在解锁、分享返回后新增广告的情况另启强匹配检测，见[亮屏与分享返回检测](splash-resume.md)。

诊断中把服务缓存设为息屏、保持模拟器实际解锁，并清空规则和例外：修复前模拟广告收到 0 次点击，修复后收到 1 次自动点击。

## 回归范围

本轮在独立 AdsBanner_Refactor 模拟器（Android 16 / API 36）录屏检查动态收起与加载交接，未操作实体手机。诊断程序和录屏在本地忽略目录 `app/build/ui-review/live-return`，不随应用发布；下列性能数据来自更早的模拟器样本。

本轮通过收起中修改真实视图颜色并采集像素，确认更新能显示在移动窗口里；额外逐帧核对列表和热力图的加载交接、新挂载行的透明度、标题保持可见以及读取波形继续推进。本轮覆盖页面、类型与排序菜单、更新日志、编辑器和应用选择弹窗，检查收起中段保留内容与自身背景、末段淡出、实际入口终点、展开途中反向及取消恢复；还覆盖左右手势、再次拖动、嵌套页面、部分可见入口、真实键盘、系统关闭动画，以及 320dp 窄屏、1.6 倍字体和深色模式。Debug、Release 构建、136 项单元测试及 lint 均通过。录屏逐帧检查未发现整帧黑屏；模拟器结果不能保证所有设备帧率，旧系统回退路径未实测。

- 实际录屏覆盖统计、名单、拦截管理页面的左右返回、工具栏返回、取消与再次拖动，以及嵌套页面返回；逐帧检查录屏，没有发现整帧黑屏。
- 类型、排序和更新日志弹窗覆盖跟手取消、提交、入口按钮持续可见及无重放按压；对浅色弹窗的实际像素另外检查背景，旧构建可复现背景丢失。
- 编辑器检查真实软键盘的两次返回；关闭系统动画后再次检查页面和弹窗返回。
- 320dp 宽度、1.6 倍字体、深色模式覆盖管理、编辑、导入导出及列表回归。核心检查覆盖自动跳过、误拦截保护、规则与例外、通知栏展开和息屏任务撤销。

此前一版在同一模拟器空闲时顺序采集页面返回的 FrameMetrics，小样本对比如下（不含各窗口首帧）。这是历史记录，不代表本次往返路径改动后的性能数据：

| 指标 | 改动前（211 帧） | 改动后（219 帧） |
| --- | ---: | ---: |
| 总耗时中位数 | 29.47ms | 29.92ms |
| 总耗时 P95 | 77.14ms | 67.44ms |
| GPU 耗时中位数 | 14.46ms | 11.48ms |
| GPU 耗时 P95 | 27.49ms | 22.92ms |

该样本中 GPU 与尾部耗时下降，总耗时中位数没有改善。模拟器数据不能推断真机帧率或续航；旧 Android 弹窗回退路径尚未在对应系统上实测。

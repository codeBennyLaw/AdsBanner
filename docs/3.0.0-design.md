# AdsBanner 3.0.0 改进依据

调研日期：2026-11-04。实现围绕现有无障碍开屏跳过、跳转守护和 B 站暂停广告清理，不增加网络代理、截图识别或小程序广告跳过。

## 参考项目

| 项目与一手资料 | 借鉴点 | 在 AdsBanner 中的落地 |
| --- | --- | --- |
| [GKD 订阅规则](https://gkd.li/guide/subscription)、[查询优化](https://gkd.li/guide/optimize) | 规则限定应用/页面、匹配时间和执行次数；通过节点 ID 快速查询 | 精确本地规则、有限启动窗口、节点 ID 查询、单次启动去重，点击前重新校验 |
| [AdAway](https://github.com/AdAway/AdAway)、[更新记录](https://github.com/AdAway/AdAway/blob/master/CHANGELOG.md) | 允许名单、暂停恢复、备份 | 例外应用、十分钟暂停与恢复、原子导入/导出规则 |
| [Blokada 5](https://github.com/blokadaorg/five-android) | 本机过滤与可见的保护状态 | 本地管理入口、明确的暂停状态、仅保存操作元数据的有限历史 |

以上作为产品和架构参考，代码独立实现。AdsBanner 使用自己的版本化 JSON 规则格式，不声称兼容 GKD 选择器或网络过滤列表。

## 分步实施

1. 通用识别与点击保护：去掉任意短语包含“跳过”的宽松兜底；点击前核对新文案、位置、窗口、可见性及父容器范围。
2. 保护控制：例外应用、限时暂停、即时取消正在等待的动作、明确通知状态。
3. 精确本地规则：应用包名、页面限定、完整节点 ID、可选文字、位置、匹配时限；导入有格式、大小和数量限制，失败不修改已有规则。
4. 拦截管理：沿用现有圆角与返回转场，提供暂停恢复、例外应用选择、本地规则管理、备份及有限操作记录。
5. 回归与真机替代验证：核心策略单元测试、模拟器规则广告页、暂停/例外/导入导出与返回转场录屏。

## 边界

- 系统界面、桌面、闹钟/计时器与嵌入的小程序页面继续优先保护，用户本地规则不能绕过这些限制。
- 通知栏保持展开；只在系统允许访问目标节点时提交节点点击，不收起通知栏，也不在遮挡下提交坐标手势。
- 本地规则只做有限开屏检测，默认一次启动最多执行一次。没有页面和广告依据时，不把普通关闭按钮当作广告。
- 操作记录仅包含应用、时间、动作与规则标识，限制条数，可清除；不记录页面全文，不保存截图，不上传。
- 规则、例外名单、暂停状态新增独立存储，旧统计与已有设置继续保留。
- 本次创建分支和 PR，不合并、不发布 Release；debug/release 都构建，诊断 APK 不作为发布附件。
